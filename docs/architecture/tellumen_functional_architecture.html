Tellumen platform architecture, one integrated diagram. A vertical functional flow, each box labelled with the technology it runs on, the arrows labelled with the data that moves, all wrapped by an operational layer. Flow: a regulated entity (banking, insurance, asset management, REIT, agri), running on a React web workspace and REST API, sends its own book — loan-tape, SOV, plots — plus Tellumen's authoritative Earth data into the engine (FastAPI, 44 routers, physics and ML scorers, H3 grid, calibration), which emits per-cell hazard scores to one governed truth on append-only PostgreSQL at r-squared at least 0.40; that one governed number forks two ways — internal decisions (Risk, Credit, Underwriting, Portfolio, Treasury, Procurement) that stay inside, and external filings (CSRD, Taxonomy, SFDR, EUDR, iXBRL) assembled as iXBRL and evidence packs that alone go downstream to supervisors (ECB, EBA, EIOPA, ESMA, national authorities, EU TRACES) who verify the same number. The operational layer — security, governance, reliability, observability — wraps every step.
